# 신규 법인(주식회사) 설립 시 지켜야 할 법적 기준

아래 표의 조문 16건은 [korean-law](https://github.com/airoasting/korean-law)의 `verify_document`로 법제처 현행 본문과 맞춰 봤고, 16건 모두 통과했다(확인일 2026-10-31, 상법은 2026-09-10 시행본 기준). 검증 결과는 [verification/](verification/) 폴더에 있다.

가장 흔한 경우인 **자본금 10억원 미만, 발기설립**을 기준으로 정리했다.

## 1. 발기인과 정관

| 기준 | 근거 |
|---|---|
| 발기인 1인 이상이 정관을 작성하고 기명날인 또는 서명 | 상법 제288조(발기인) |
| 정관 절대적 기재사항: 목적, 상호, 발행할 주식 총수, 1주의 금액(액면주식), 설립 시 발행 주식 수, 본점 소재지, 공고 방법, 발기인 성명·주민등록번호·주소 | 상법 제289조(정관의 작성, 절대적 기재사항) |
| 현물출자, 재산인수, 설립비용, 발기인 보수는 정관에 적어야 효력이 생김 | 상법 제290조(변태설립사항) |
| 정관은 원칙적으로 공증인 인증이 필요함. **자본금 10억 미만 발기설립은 발기인 기명날인·서명만으로 효력이 생김(공증 면제)** | 상법 제292조(정관의 효력발생) |

## 2. 자본금과 주식 납입

| 기준 | 근거 |
|---|---|
| 액면주식 1주의 금액은 100원 이상으로 균일해야 함 | 상법 제329조(자본금의 구성) |
| 발기인은 인수한 주식의 가액을 지체 없이 전액 납입함 | 상법 제295조(발기설립의 경우의 납입과 현물출자의 이행) |
| 은행이 납입금보관증명서를 발급함. **10억 미만 발기설립은 잔고증명서로 대체 가능** | 상법 제318조(납입금 보관자의 증명과 책임) |

## 3. 기관 구성

| 기준 | 근거 |
|---|---|
| 이사는 3명 이상이 원칙. **10억 미만 회사는 1명 또는 2명도 가능**(이사회 없이 각 이사가 회사를 대표) | 상법 제383조(원수, 임기) |
| 이사 임기는 3년을 넘지 못함 | 같은 조 |
| **10억 미만 회사는 감사를 두지 않을 수 있음** | 상법 제409조(선임) |

## 4. 상호와 설립등기

| 기준 | 근거 |
|---|---|
| 같은 특별시·광역시·시·군에서 같은 업종으로 남이 이미 등기한 상호는 쓸 수 없음 | 상법 제22조(상호등기의 효력) |
| **설립등기 기한**: 검사인 등의 조사가 끝난 날(발기설립) 또는 창립총회가 끝난 날(모집설립)부터 **2주 내** | 상법 제317조(설립의 등기) |
| 본점 소재지에서 설립등기를 해야 법인이 **성립**함 | 상법 제172조(회사의 성립) |
| 설립등기 때 등록면허세를 냄. 수도권 과밀억제권역에서는 중과될 수 있음 | 지방세법 제28조(세율) |

## 5. 설립 후 세무 신고

| 기준 | 기한 | 근거 |
|---|---|---|
| 법인설립신고 | 설립등기일부터 **2개월 이내** | 법인세법 제109조(법인의 설립 또는 설치신고) |
| 사업자등록(이걸 하면 설립신고를 한 것으로 봄) | 사업 개시일부터 **20일 이내**(개시 전에도 신청 가능) | 법인세법 제111조, 부가가치세법 제8조(사업자등록) |

## 위 표에 없는 확인 사항

- **업종별 인허가·등록**: 건설업, 식품, 금융, 통신판매업 등은 해당 법령에 따라 따로 신고·허가가 필요하다.
- **4대보험**: 직원을 고용하면 성립신고를 해야 한다(대표이사 1인 법인도 국민연금·건강보험은 가입 대상).
- **법인 계좌 개설**과 **법인인감 신고**(등기소)도 필요하다.
